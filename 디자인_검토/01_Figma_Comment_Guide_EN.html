How to add comments in Figma
  1. Open the Figma file UI UX Design → select DEX in the left page list
  2. Press C to enter comment mode (or click the speech bubble icon at the top left)
  3. Find the frame listed under Comment location on each card below and click it
  4. Click Copy, paste into the comment field with Ctrl+V → send
  5. After posting, check the square on the left of the card to mark it complete
Finding a frame — Paste the exact frame name into Search (magnifying glass) at the top of Figma to jump to it. Example: SCREEN-LABEL · H5 Signed in, DEX wallet linked

Terminology — Use cashback in English. The Korean originals distinguish the legacy Korean term from the approved Korean term; both are translated as cashback here. References to Korean wording changes are explained explicitly. Prototype reference images are English renders of 사용자화면_DEX_V2.1.html, including English translations for Korean text remaining in EN mode. Original Figma screenshots are retained for comparison.

Comment bodies are plain text. Figma comments do not support bold or code formatting, so formatting symbols are omitted. Copied text will appear exactly as shown.
