# 미결정·추가 확인 목록

기준: 2026-10-23 R-34까지의 결정 기록 + 이번 대화 + 두 프로토타입 소스 검토.

**이 문서는 결정을 요청하는 목록입니다. 아래 권고나 선택지를 확정으로 취급하지 않습니다.** 이번 작업에서 원본 정책·프로토타입을 임의 변경하지 않았습니다.

## 1. 이번 대화로 닫힌 항목

| 항목 | 확정 내용 |
|---|---|
| 다중 출금의 일부 실패 | 성공한 건은 성공 유지, 실패한 건만 실패 처리. 기존 CEX 처리 방식 사용 |
| 결과 이메일 단위 | 계정별로 성공·실패 이메일 각각 발송. DEX는 지갑 계정 식별 |
| 여러 결과를 한 이메일로 묶을지 | 개별 이메일로 확정됐으므로 다시 묻지 않음 |

비회원은 기존의 알림 없음 정책을 유지합니다. 전송 결과가 불명확한 상황의 판정·재확인 기준은 아래에 남깁니다.

## 2. 기존 한도 관련 항목

| 항목 | 쉬운 설명 | 현재 상태 |
|---|---|---|
| B-3-1: CEX·DEX 한도 관계 | UID와 지갑이 하나의 연동 한도를 함께 쓸지, 각각 별도 한도를 쓸지 | 미정 |
| 고정 총량 대안 | 거래소 수와 무관하게 회원당 최대 N개로 정할지 | 대안일 뿐 미확정. N도 미정. 12는 예시 |
| Processing 포함 | 연동 확인 중인 계정도 한 칸으로 셀지 | 미정 |
| 회원별 사용량 조회 | 회원이 가진 CEX UID·DEX 지갑 수와 한도 점유 현황을 운영자가 확인 | 필요성은 확인. 합산/분리 정책과 상세 표 구성 미정 |
| 플래그 대응 | 기존 `linkable`과 실제 생성 폼의 가입 가능여부가 같은 필드인지 | 개발 확인 |

이미 정해진 DEX 명세: Active 포함, 같은 주소를 다른 DEX에 연동하면 각각 계산, 지갑 제거 시 칸 반환, 한도 감소 시 기존 연동 유지·신규만 차단, 서버의 동일 트랜잭션 안에서 한도 검사.

회원별 예외 한도를 운영자가 올려주는 기능은 확정 요구사항이 아닙니다. 최신 기록에서는 별도 결정 요청에서 내려갔으므로 다시 확정 기능처럼 올리지 않습니다.

## 3. 방금 추가된 N-1~N-6

| ID | 결정할 내용 | 검토 중 취급 |
|---|---|---|
| N-1 | DEX 페이백을 마일스톤 진행바에 포함할지 | 기존 문서와 화면이 상반됨. 포함/제외를 임의 선택하지 않음. VIP 범위 밖은 유지 |
| N-2 | 비밀번호 변경 후 72시간·출금 이메일 실패 후 24시간 계정 제한을 DEX에 어떻게 적용할지 | 기존 인증 명세와 신규 확인 요청의 충돌도 함께 정리 필요. 미적용이라고 단정하지 않음 |
| N-3 | 0.05 USDT 미만을 0으로 표시하는 기존 규칙의 DEX 적용 범위 | 표시와 원장 정밀도 구분 필요. 임의 반올림·잔액 삭제 금지 |
| N-4 | 랭킹에서 0.01 USDT 미만 제외 기준의 DEX 적용 | 계산·표시 기준과 함께 확인 |
| N-5 | 소유권 인증이 없는 DEX의 ‘연동 완료’와 Verified 의미 정합 | D-4의 기존 사용자 결정과 기준선 문구가 충돌. 배지 의미를 새로 정하지 않음 |
| N-6 | 더 이상 사용자 출금에 쓰지 않는 DEX 출금 딥링크 필드의 처리 | 삭제/다른 용도 전환 미정. 레퍼럴 가입 링크와는 별개 |

| 다중 출금 요약의 대표 계정 | 첫 계정과 +N으로 표시할지, 계정 수 중심으로 표시할지 명시 부족 | 화면 기준 |
| 첫 출금 혜택의 중복 인정 | CEX로 이미 받은 회원이 DEX 첫 출금으로 다시 받는지 기존 혜택별 완료 기준 확인 필요 | 정책 |

| 이벤트·쿠폰 발송의 ‘미연동/없음’ | CEX만 없음인지 모든 계정 없음인지 기존 저장 조건의 실제 의미 확인 필요 | 운영·개발 |

## 6. 미결정으로 다시 올리지 않을 명확한 수정 항목

- 출금 예시 합계 10+31.68+120은 161.68이라는 계산.
- A=0, B=20일 때 최소 출금까지 필요한 페이백은 5라는 계산.
- 비회원 출금은 단일 지갑이고 회원 다중 목록으로 보내면 안 됨.
- DEX도 이벤트·초대 리워드 지원.
- DEX 챌린지·부스트·소유권 인증 제외.
- Standard 연동 차단·경고 없음.
- LINK UID 3 USDT 쿠폰의 DEX 제외.
- 일반 회원 초대 출금의 DEX 포함과 어드민 Affiliate 고정 지급 계정의 CEX 전용.
- 사용자 지갑 축약 표시, 어드민 전체 확인, 이메일 전체 주소.
- 고객 요청액에서 가스비를 공제하지 않음.
- Lighter 일별 원장 없으면 맥스보드 미운영. 일별 원장 확보 여부만 대기.
- 계산기의 요율은 거래소 레코드 참조, 전용 설정은 슬라이더 범위.
