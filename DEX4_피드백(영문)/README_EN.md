# DEX PRD Feedback - English Annotation Copies

This folder contains 13 PDFs with English feedback annotations. Original source PDFs were not modified.

- All 131 feedback-bearing annotations and their original positions, colors, IDs and confirmed decisions are preserved. Repeated annotations contain the same translation.
- Comments remain native PDF annotations. Use the comments panel or select a highlight/note to read them.
- `feedback_comments_EN.md` provides all 53 distinct comment bodies in a searchable reference.
- Product terminology uses **cashback**, including the underlying PRD text. Five source-copy PDFs received limited copy corrections: 13 terminology replacements, five corresponding grammar corrections, and one romanized personal name.
- `/payback` is preserved only where it denotes the existing URL path. It is a technical identifier, not translated product terminology. Renaming it would change the documented destination.
- Review observations and later confirmed decisions are translated in their original order; this translation does not introduce new policy decisions.
- `validation.json` records the completed audit. `QA_EN.md` describes its scope and results.
