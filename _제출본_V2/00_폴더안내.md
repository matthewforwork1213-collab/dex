## 2-2. 2026-10-21 2차 — 어드민 거래소 선택 지점

작업 중 어드민 캡처 2종을 추가로 확인해 반영했습니다.

| 화면 | 반영 위치 |
|---|---|
| `푸시 > 수동 푸시 > 푸시 선택` | 4번 문서 **7-5** |
| `이메일 > 이메일 캠페인 > 발송 대상 필터` | 4번 문서 **7-6** |
| **거래소 선택 지점 전수 점검표** | 4번 문서 **7-7** |

### 확인된 것

**① 두 화면은 별개 구현입니다.** 공용 컴포넌트가 아니라 각각 고쳐야 합니다.

| | 수동 푸시 | 이메일 캠페인 |
|---|---|---|
| 거래소 선택 | 멀티 칩 + AND/OR | 단일 드롭다운 + `=` |
| 거래소 목록 | **약 40개** (test 포함) | **18개** (test 없음) |

**② 거래소 칩 추가가 전부가 아닙니다.** 금액·이력 조건에 DEX가 포함되는지가 더 중요합니다.
포함하지 않으면 **페이백을 받고 있는 DEX 회원이 "페이백 없는 회원" 대상 푸시를 받습니다.**

**③ 전수 점검표 — 23개 지점 중 10개만 직접 확인했습니다.**
```
A. 확인 완료   10곳
B. PRD 확인     3곳
C. 캡처 필요   10곳   ← 쿠폰 · 뉴스레터 · 이벤트 안내 이메일이 우선
```
