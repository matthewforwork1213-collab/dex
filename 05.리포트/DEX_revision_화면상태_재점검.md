# DEX(revision) 사용자 화면 상태 재점검

2026-11-25 · [검토한 Figma 페이지](https://www.figma.com/design/hsa3bSV9QmFTe2jsf6tzTm/UI-UX-Design?node-id=28960-125519)

## 후속 반영 결과

[Figma 진입·복귀 경로도](https://www.figma.com/design/hsa3bSV9QmFTe2jsf6tzTm/UI-UX-Design?node-id=29005-126470)에서 대표 사용자 여정 13개와 기능별 상태 보드 8개를 열 수 있다. 상태 158개마다 출발 화면, 응답 조건, 사용자 표시, 다음 동작 또는 현재 화면 유지 조건을 연결했다. 아래 ‘우선 수정할 항목’과 ‘나머지 화면별 판정’은 수정 전 점검 결과다.

- 사용자 확인에 따라 독립 출금 시안은 제외했다. 홈·허브·지갑 상세에 잔액과 비활성 `Auto Claim`을 표시한다. 아래에 기록한 종전 독립 출금 목록과 해당 페이지 진입은 현재 디자인의 개발 대상에서 제외한다.
- 웹 O1·O10·O16의 버튼과 거절 사유를 수정했다. 모바일 라이트·다크에서 제출 확인의 `Cancel`은 업로드한 파일이 남은 화면, 실패창의 `OK`와 `Replace file`은 파일 선택 화면으로 연결됨을 확인했다.
- 캔버스에서 상태별 진입 화살표 158개, 후속 동작·상태 유지 화살표 186개, 대표 경로 화살표 39개를 확인했다. 실제 앱의 파일 보존·중복 신청 방지·서버 갱신 검증과 정책 보류 항목은 별도다.

**개발 판단**　정상 흐름과 여러 예외는 구현에 착수할 수 있다. 소유권 신청, 지갑 연동 중 인증 실패, 공개 데이터 장애는 화면만 보고 구현하면 사용자에게 다른 동작을 제공할 수 있다. 이 세 흐름의 인수 조건을 먼저 고정해야 한다.

검토 범위는 현재 페이지에 등장하는 사용자 기능이다. 웹·모바일, 라이트·다크, 같은 화면의 스토리 사본, 필터와 팝오버를 포함해 25개 화면 묶음의 하위 항목 292개를 목록화했다. 이 숫자에는 같은 상태의 중복과 개별 컨트롤이 포함된다. 주요 판정에는 프레임 이름 외에 실제 표시 문구, 버튼 속성, 연결 목적지 또는 렌더링 이미지를 사용했다. 앱의 실제 API 호출, 중복 방지, 키보드 조작은 별도 실행 검증 대상이다.

기준 문서는 [최종 정책](../00_DEX_최종정책.md), [요구사항 정의서](../02.기획문서/요구사항정의서.md), [사용자 프론트 명세](../02.기획문서/프론트_기능명세서_사용자.md), [사용자 API](../02.기획문서/API스펙_사용자.md)다. 아래의 ‘인계 필요’는 해당 페이지에서 구현 근거를 특정하지 못했다는 뜻이다. 공통 CEX 화면을 재사용할 때는 원본 컴포넌트와 DEX에 넘겨야 할 값·복귀 동작을 연결하면 된다.

## 수정 기록과 확인 범위

- 웹에서 기본 문자열 `Label`이 남아 있던 버튼 44곳의 속성 변경이 처리됐다. 소유권 관련 버튼 19곳과 여러 시안에 반복된 홈 잔액 버튼 25곳이다. 홈 잔액 버튼은 `Auto Claim`·비활성으로 바꾸고 클릭 동작을 제거했다. O8은 `OK`, O9는 `Contact Support / Try again`, O10은 `Cancel / Submit Claim`으로 바꿨다.
- O1과 같은 타인 지갑 스토리 두 곳, O16은 위 표의 정책 문구로 추가 수정해야 한다. 변경 건수에는 이 위치도 포함된다. 모바일 화면과 프로토타입 복귀 경로는 이 수정 건수에 포함되지 않는다.
- 이 판정의 범위는 디자인 인계다. 중복 신청 방지·실제 파일 보존·서버 반영·키보드 포커스는 실행 결과를 확인해야 닫을 수 있다. 언어별 문구와 운영 미결정 항목은 최종 정책의 결정 상태를 따른다.
