## 2. 공통 규칙

| 규칙 | 내용 |
|---|---|
| 움직임 줄이기 | `prefers-reduced-motion: reduce`이면 전환을 생략한다 — CSS(`00-core.css` 끝 미디어 쿼리: 모든 transition·animation 0s) + JS(`MOTION.reduced()` · `UI.reduced()` · pt-runtime `reduced()`가 참이면 애니메이션을 만들지 않고 결과만 그린다) |
| 같은 자리 내용 교체 | 이전 내용을 지우고 새 내용을 `opacity 0→1` + `translateY(var(--m-shift)) → 0`, `--m-std` `--e-io`. 여러 덩어리면 30ms 간격 |
| 숫자 바뀜 | 계산 결과 금액은 이전 값 → 새 값 보간(`--m-std`, 슬라이더 클릭·키보드는 `--m-fast`, 끄는 중에는 바로 반영). 처음 보이는 큰 % 숫자는 굴림(`--m-roll`) |
| 레이어 | 열림 = 배경막·내용 `opacity 0→1` + 내용 `translateY(30px)→0` · 닫힘 = `opacity 1→0` + `translateY(0→-30px)`, `--m-modal` `--e-io`. 드로어는 `translateX(100%)` |
| 펼침 | 높이 0 ↔ 내용 높이, `--m-std` `--e-io`, `overflow:hidden`(끝나면 해제) |
