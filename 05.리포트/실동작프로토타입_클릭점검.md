# 실동작 프로토타입 클릭 점검 (수집 스냅숏 페이지)

| 항목 | 내용 |
|---|---|
| 대상 | `_프로토타입_실사이트/` 수집 스냅숏 페이지(`pages/*`) + 런타임 `pt-runtime.js` + 셸 `index.html`. DEX 앱 화면(`dex/*` — 허브 · DEX 랜딩·상세 · 캐시백 요약 · 지갑 상세 · 소유권 인증)은 별도 담당이 다시 만들어 이 점검 범위에서 뺐다 |
| 방법 | 로컬 서버(`python -m http.server`, 저장소 루트)로 셸 `index.html#key=…&auth=…&view=pc\|mo`를 열고 iframe 안의 보이는 클릭 요소(a · button · [role=button] · [data-pt-sig] · 탭·칩·토글·아코디언·캐러셀 화살표·입력 · 커서가 손가락인 요소)를 하나씩 눌러 결과를 분류. 오버레이(수집 조각)가 열리면 그 안의 요소도 누름. 셸 이동은 기록만 하고 막아 같은 화면에서 다음 요소를 누름. DOM이 바뀌면 다시 불러옴 |
| 실사이트 대조 | 라이브 https://tethermax.io/en 의 같은 요소를 Playwright로 눌러 열림 유지·닫힘 조건·전환 시간·이동 대상·오류 문구를 채집(게스트만 — 회원 세션 없음). 제출 버튼은 라이브에서 누르지 않음 |
| 점검 스크립트 | scratchpad `clickaudit.py`(클릭 전수) · `agg.py` · `rep.py`(집계) · `genacts.py`(보완표 생성) · `livediff.py`(라이브 본문 대조) · `liveform4.py`(라이브 폼 채집) · `formtest.py` · `rowtest.py` |

## 3. 입력 폼

라이브 가입·로그인·비밀번호 재설정 화면에서 같은 칸에 틀린 값을 넣어 채집했다(같은 컴포넌트 `OutlinedFloatingInput` · `HelperText` 클래스를 수집 CSS 그대로 씀).

| 동작 | 라이브 측정 | 프로토타입 |
|---|---|---|
| 포커스 | 칸 `focused · floated` — 라벨이 테두리 위로(.15s), 테두리 색 | 같음 |
| 벗어남 | 값이 있으면 `floated`. 형식이 틀리면 `error` + 아래 문구 | 같음 |
| 고쳐 입력 | 맞는 값이 되면 바로 오류가 사라짐 | 같음 |
| 이메일 문구 | 가입·로그인 `Enter a valid email address` · 재설정 빈 값 `No email has been entered.` / 형식 `Enter a valid email address.` | 같음 |
| 비밀번호(가입) | 입력하면 규칙 2줄 `8-16 characters.` · `At least one number and special character (*!@#).`, 맞으면 초록 체크 · 벗어날 때 틀리면 빨간 테두리(문구 없음) | 같음 |
| 비밀번호(로그인) | 벗어날 때 8~16자가 아니면 `8-16 characters.` | 같음 |
| 눈 아이콘 | 보기/숨기기 + 아이콘 바뀜 | 같음 |
| 약관 동의 | 처음 체크됨, 눌러 해제/체크 | 같음 |
| 초대 코드(선택) | 1~3자 `Enter at least 4 characters` | 같음 |
| 제출 버튼 활성 | 로그인: 이메일 + 8~16자 → 활성. 재설정: 이메일 → 활성. 가입: 이메일 · 비밀번호 규칙 · 약관 · 초대 코드를 채워도 Cloudflare 확인(Turnstile)이 더 있음 | 가입은 Turnstile 없이 나머지 조건으로 활성 |
| 랜딩·검색 `Sign Up Now` 이메일 | `/en/signup?email=…` — 가입 화면 이메일 칸에 채워 바로 검증 | 같음 |
| 제출 후 | (라이브에서 제출하지 않음) | 로그인 → 회원 홈 · 가입 → 회원 홈 · 재설정 → 처리 토스트 |

화면: `4_10`(라벨 이동) · `4_11`(비밀번호 규칙·오류) · `4_12`(눈 아이콘·조건 충족·활성) · `4_13`(이메일 오류) · `4_14`(로그인 오류 문구) · `4_15`(재설정 모바일 빈 값) · `4_16`(랜딩 이메일 → 가입 검증).
