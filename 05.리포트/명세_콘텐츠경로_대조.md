## 2. 고친 불일치

| # | 경로 | 어긋났던 내용 | 고친 내용 |
|---|---|---|---|
| 1 | 단계 가이드 | 사용자 API가 이미지 1장 · `safetyNote` 필드, 화면이 목록 라벨과 패널 제목을 따로 둠 · 경고 박스 | 영상 2개, 제목 1개, 경고·안전 메시지는 Description 안(G-437) |
| 2 | 오퍼 박스 | 사용자 쪽은 레코드 요율 + 토글 + 단계 표, 어드민 쪽은 Right Box 탭 — 관계 정의 없음 | 탭 1개 = 토글 1칸(G-438), API-004 `offerBox.tabs[]` |
| 3 | FAQ | 어드민은 섹션당 자유 텍스트 한 칸, 화면·API는 질문·답변 단위 | 섹션 안 질문·답변 쌍(G-439) |
| 4 | 상세 기본 | `Additional Notes`의 표시 위치 없음 · 외부 버튼 필드가 Right Box 링크와 중복 | 자격 안내 줄로 표시, 버튼 필드 삭제(G-440) |
| 5 | 이유 카드 | API에 카드별 `title` · `body`가 있으나 어드민은 썸네일 + 설명뿐, 섹션 제목 출처 불명 | API를 어드민 필드에 맞춤, 제목 = `Key Features Title` |
| 6 | 마지막 띠 | API-004에 배너가 없음, 화면은 고정 문구 색 띠 | API-004 `banner` 추가, 화면 = 어드민 배너 |
| 7 | DEX 랜딩 | API-127 `areas` 구조 미정의, API-003에 영역 5개 · 카드 필드 일부 없음 | API-127 · API-003 키를 정책 ELC 표에 맞춰 정의 |
| 8 | 소유권 녹화 가이드 | 사용자 화면은 DEX별 이미지가 필요한데 내려 주는 API가 없음 | API-005 `ownershipGuide` 추가 |
| 9 | 지갑 주소 찾기 | API-005는 「문구·스크린샷이 모두 없으면」 미제공, 요구사항은 「둘 중 하나라도 없으면」 | API-005를 요구사항에 맞춤 |
| 10 | Lighter 주중 | G-059 · REQ-047은 `Accruing` 추정 줄, G-100 · REQ-303은 미표시 | 미표시로 통일(G-100), enum `ACCRUING_ESTIMATE` 삭제 |
| 11 | 확정 결정의 ❓ | 부록 G에서 확정된 항목이 본문·REQ에 ❓로 남음(G-053 · G-047 · G-261 · G-269 · G-274 · G-330 · G-344 · G-348 · REQ-626) | 확정 내용으로 표시 |

프로토타입(전체 · V2.2)도 같은 기준으로 고쳤다. V2.2 어드민 Edit Detailed Content는 가이드 단계 수 1~8 · 구조안 ①② · Key Features 3개 등 결정 전 내용을 확정 기준으로 바꿨다.
