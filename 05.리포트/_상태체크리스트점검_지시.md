# 상태 체크리스트 점검 지시 (명세와 무관하게 빈칸 찾기)

## 목적
앞선 전수 점검은 「명세에 있는 상태가 Figma에 있는가」였다. 이번에는 **명세에도 Figma에도 없는 상태**를 찾는다. 화면·동작마다 아래 체크리스트를 하나씩 대입해, 개발자가 「이 경우 화면은?」 하고 물을 만한 빈칸을 모두 적는다.

## 체크리스트 (화면마다)
| 분류 | 확인할 것 |
|---|---|
| 데이터 | 첫 로딩(스켈레톤/스피너) · 빈 상태(0건) · 일부만 있음 · 많음(페이지네이션/더보기/긴 텍스트 줄바꿈) · 지연(데이터 늦음) |
| 오류 | 서버 오류(5xx) · 네트워크 끊김/타임아웃 · 일부 영역만 실패 · 권한 없음(401/403) · 존재하지 않음(404) · 요청 과다(429) · 재시도 버튼과 그 결과 |
| 사용자 동작 | 화면의 **모든 버튼·링크·입력**마다: 누르면 무엇이 일어나는지, 성공 피드백(토스트/스낵바/화면 이동), 실패 피드백, 처리 중(버튼 로딩·중복 클릭 방지), 비활성일 때 이유 표시 |
| 입력 | 빈 값 · 형식 오류 · 길이 초과 · 붙여넣기 · 공백/대소문자 · 서버 검증 실패 · 입력 유지(실패 후) |
| 사용자 상태 | 게스트 · 회원(연동 0) · 회원(CEX만/DEX만/둘 다) · 확인 중 계정만 · 세션 만료 중 동작 · 지역/언어 |
| 오버레이 | 모달·시트 닫기(X·바깥 클릭·뒤로가기) · 모달 위 오류 · 열린 채 상태 변경 |
| 복사·공유 | 복사 성공 토스트 · 클립보드 권한 거부 · 공유 시트 |
| 모바일 | PC 상태마다 모바일 대응이 있는가 · 하단 고정 버튼과 키보드 |
