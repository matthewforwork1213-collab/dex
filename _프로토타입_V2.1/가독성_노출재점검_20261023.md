# 가독성과 화면 노출 재점검

2026-10-23. 사용자가 첨부한 계정 상세 화면과 이전의 화면 노출 요구를 기준으로 사용자·백오피스 V2.1을 다시 수정했습니다. V2 원본과 V3는 수정하지 않았습니다.

## 가독성 문제와 수정

| 문제 | 수정 |
|---|---|
| 잔액 카드와 타임라인 카드의 테두리가 붙음 | 두 카드를 세로로 쌓는 컨테이너에 PC 20px, 모바일 미리보기 18px 간격 적용 |
| 거래소명·뒤로가기·주소가 좁은 헤더에 붙음 | 기존 요소의 배치를 정돈하고 이름·식별자·상태의 줄 높이와 간격 구분 |
| 신청 가능 금액과 나머지 금액의 강조가 같음 | 신청 가능 금액을 24px로 강조, 통화와 보조 정보는 별도 크기 적용 |
| 진행 막대와 파란 출금 버튼이 붙음 | 진행 막대 아래 20px 간격, 출금 버튼 최소 높이 46px |
| 타임라인·주간 내역이 작고 촘촘함 | 타임라인 3칸·주간 7칸 구조 유지, 셀 내부 간격과 글자 크기 보완. 좁을 때 주간 영역 안에서만 스크롤 |
| 실제 UI에 없는 클릭 점선 | 두 HTML의 제품 미리보기 전체에서 점선용 클래스 제거. 키보드 포커스 표시는 유지 |
| 숨긴 설명 패널의 빈 열이 넓은 화면에 남음 | 설명 패널과 도구 제거, 바깥 미리보기 레이아웃을 한 열로 정리 |

색상·Wanted Sans·두 열의 계정 상세·카드·타임라인·주간 내역 등 V2 구성은 유지합니다. 실제 서비스 버튼을 추가하지 않았습니다.

## 추가로 발견한 화면 노출 오류

- **리그:** 보상용 ‘수령 계정’ 폼을 재사용하던 오류를 제거했습니다. V2 리그 개요와 ‘참가할 계정 선택’ 모달을 분리해 외부 상태로 선택합니다. 버튼은 V2의 ‘취소 / 확인’입니다. 팀 생성 정책 설명을 제품 본문에 붙이지 않습니다. DEX 스폰서가 확정된 것처럼 보이던 예시 교환명도 제거했습니다.
- **챌린지:** 게이지 화면과 수령 계정 모달을 분리했습니다. 미완료 게이지에 임의로 추가했던 수령 버튼을 제거했습니다. 수령 모달은 CEX만 표시하며 CEX 전용 안내는 해당 챌린지 화면에 유지합니다.
- **하위 회원 계정:** 실제 V2의 계정 목록 모달로 표시하고, 추가했던 계정 상세·관리 버튼은 제거했습니다.
- **관리자 상태 누수:** 다른 화면에서 선택했던 포인트 모달이나 콘텐츠 미리보기가 새 화면에 계속 남는 문제를 수정했습니다.
- **내부 메모:** 관리자 본문의 백엔드 처리 지침과 계산기·집계 구현 설명, 신규 변경 마커를 제거했습니다. 실제 운영 제한·입력 안내는 유지합니다.
- **원본 미디어 자리표시:** 제품 본문에서 ‘가입 화면 스크린샷’, ‘이벤트 배너’, ‘Key Features 4개’처럼 제작자에게 하는 표시를 제거하거나 실제 섹션명으로 정리했습니다. 연결되지 않은 미디어는 이미지 영역으로 남겼습니다. 실제 원본 이미지와 거래소별 최종 콘텐츠는 기존 미디어·콘텐츠 보류 항목이며 임의 생성하지 않았습니다.

## 이전 요구 재확인

| 요구 | 확인 |
|---|---|
| 계정 상세의 추가 버튼 제거 | 본문 출금 버튼만 유지, V2 뒤로가기·전체보기 유지 |
| 혜택 목록의 하단 공통 안내 제거 | 미노출. CEX 전용 설명은 보상 상세·챌린지 등 필요한 위치에 유지 |
| 공식 파트너 캐러셀은 서비스 소개 | 서비스 소개만 표시, 홈에는 표시하지 않음 |
| 홈·서비스 소개의 통합 출금 피드 | 양쪽 모두 CEX·DEX 완료 건 포함 |
| 출금 인증·계정별 결과 화면 제외 | 사용자 탭·흐름에 없음. V2 정상 신청 완료와 공유 화면 유지 |
| 선행 입력 없이 화면 확인 | 완료·공유·연동 완료·비회원 출금 직접 진입 유지 |
| 시연 도구·화살표 플로우 제거 | 두 HTML 전체에서 제거 상태 유지 |
| 상태 변경만 바깥에서 제공 | 회원·비회원·미연동, 리뷰 유무, 리그 참가 계정 유무 등 외부에서 선택 |

‘미연동’은 CEX·DEX 전체에서 연동된 계정이 없는 상태입니다. 외부 상태 선택용 데이터를 표시할 때 실제 공용 계정 배열을 삭제하지 않습니다.
