# V2.1 모달 표시 정리

2026-10-23. 사용자 화면과 백오피스의 모달을 모두 배경 화면 위에 표시하도록 수정했습니다. 사업 정책·한도 설정 화면을 추가한 변경은 아닙니다.

2026-10-26 재수정: 화면을 일반 카드로 만든 뒤 모달로 옮기는 후처리에 의존하지 않도록, 화면 생성 결과 자체에 배경·음영·모달을 포함했습니다. 로컬 파일/IDE 미리보기에서 주소 변경이 거부돼도 메뉴 이동과 화면 생성이 중단되지 않습니다. 두 HTML 상단에 `V2.1 | 2026-10-26`을 표시합니다.

## 적용 범위

| 파일 | 화면 |
|---|---|
| 백오피스 | 회원 연동 계정, 제휴사 등록, 레퍼럴 계정 마진 수정, 거래소 순위 수정, 포인트 적립률 관리, 강조할 거래소 |
| 사용자 | 회원 거래소 선택·계정 연동 입력·연동 완료·귀속 불일치·확인 중·중복·오류·지갑 주소 안내 |
| 사용자 | 회원/비회원 출금 목록·출금 가능 없음·신청 완료·공유 |
| 사용자 | 쿠폰 사용 계정 선택, 초대 리워드 수령 계정 선택, 챌린지 보상 계정 선택, 리그 참가 계정 선택/계정 없음, 하위 회원 연동 계정 조회 |

모달이 열리지 않은 상태의 목록·상세·편집 화면, 비회원 조회 페이지는 기존 페이지 구성을 유지합니다. 쿠폰 사용 완료·포인트 목록·리그 기본 화면도 별도 모달을 강제로 열지 않습니다. 선행 입력 없이 상단 화면·상태에서 직접 확인할 수 있습니다.

## 공통 동작

- 모달 뒤에 실제 목록·홈 등 배경 페이지를 표시하고 어두운 음영을 적용합니다.
- 배경은 `inert`와 `aria-hidden`으로 조작·키보드 접근을 차단합니다.
- 닫기 버튼, Escape, 배경 클릭으로 닫습니다. 취소·저장 등 기존 제품 버튼은 유지합니다.
- 모달 내부에 키보드 포커스를 유지하고, 계정 선택·입력·폼 저장·검증을 그대로 연결합니다.
- 모달 높이를 미리보기 안으로 제한하고 긴 본문은 내부에서 스크롤합니다. 넓은 표는 표 내부에서 가로 스크롤합니다.
- 검토용 상태 변경과 변경점 설명은 제품 미리보기 밖에 둡니다. 모달이 열렸을 때 변경점은 모달 내부의 해당 요소에만 표시합니다.
- 레퍼럴 마진 화면은 외부 화면 상태에서 수정 모달을 다시 열거나 목록을 볼 수 있습니다.

## 검증

`check-modals.cjs` 176/176, `check-dom.cjs` 93/93, `check-design.cjs` 630/630, `check-changes.cjs` 320/320, `check.cjs` 462/462 통과.

모달 검사는 로컬 파일 주소와 주소 변경이 차단된 IDE 미리보기 조건에서 상단 메뉴를 실제 클릭하는 경로도 포함합니다. 직접 화면 생성 시에도 모달 음영과 배경 차단 속성이 포함되는지 검사합니다.

검증은 오프라인 JSDOM에서 실제 DOM·CSS 속성·이벤트·폼을 대상으로 수행했습니다. 브라우저 스크린샷이나 실제 기기에서의 시각 검증은 포함하지 않습니다. 로컬 파일 브라우저 열기는 앞서 브라우저 보안 정책으로 차단되어 우회하지 않았습니다.

소스는 `src/modals.js`와 `src/refine.css`, 빌드는 `build.cjs`입니다. 기존 V2 원본과 V3는 수정하지 않았습니다.
