## 표시 방식

- 기본은 체크 해제이며 기존 제품 미리보기만 표시합니다.
- 체크하면 현재 화면의 변경 영역에 색상 테두리와 번호가 표시됩니다. 오른쪽 설명과 번호가 대응하며, 작은 화면에서는 설명이 아래로 이어집니다.
- 번호를 클릭하면 해당 설명을, 설명을 클릭하면 해당 화면 영역을 선택합니다. 번호 클릭으로 제품 버튼의 출금·저장·화면 이동이 실행되지 않습니다.
- 체크 상태는 화면·상태·언어·모바일 미리보기 전환 시 유지됩니다.
- 해제하면 테두리·번호·설명 패널을 모두 제거합니다. 폼 입력값·선택값·계정·잔액·신청 데이터는 바꾸지 않습니다.
