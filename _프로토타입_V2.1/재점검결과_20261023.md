# V2.1 재점검 결과

사용자 요청에 따라 V2.1 사용자·백오피스 두 HTML을 수정했습니다. V2 원본과 V3는 수정하지 않았습니다. 화면 전체를 다시 디자인하지 않고 V2의 상단 GNB·계산기·출금 카드·관리자 틀을 유지했습니다.

## 확인한 주요 정책

- CEX·DEX 통합 한도, 확인 중 포함. 구체적 최대 숫자는 기존 설정 연결 대상으로 유지.
- 0.01 USDT 소액 기준, 뒤 4자리 마스킹과 본인 지갑 전체 주소 보기.
- 계정별 매칭·최소 출금액·합계와 일부 성공 유지.
- 회원 접수 이메일 1회 → 계정별 최종 결과 이메일. 비회원 이메일 없음.
- UID 미션·챌린지 CEX 전용, 일반 리워드 DEX 포함.
- 공유는 신청 완료 이후, DEX 첫 출금 인정.
- 회원 보안 제한과 비회원 미적용 구분.
- 홈·서비스 소개의 CEX/DEX 통합 캐러셀·완료 출금 피드.
- 포인트 관리의 DEX 4곳·4개 비율·미설정 0.
- V2 내장 폰트 데이터와 상단 GNB 보존.

## 검증 범위

- **화면·계산·경로 검사 534개 통과.** 한국어/영어·하위 상태별 생성과 금액·정책 조건 검사.
- **오프라인 DOM 검사 102개 통과.** 실제 HTML 파싱 후 클릭·변경·폼 제출 이벤트로 회원/비회원 출금, 결과 이메일, 설정 저장, 연동 필터, 상세 이동, 캘린더, 가이드, 표시 순서 등을 확인.
- DOM 검사 중 관측한 JavaScript 실행 예외 0건.
- 관련 결과: `검증결과.json`, `DOM검증결과.json`.

DOM 검사는 로컬 캐시에 있던 JSDOM을 사용하며 네트워크나 브라우저를 실행하지 않습니다. 이전의 빈 DOM 대체 객체 검사에서 확인하지 못하던 이벤트 연결과 폼 동작을 추가로 확인한 것입니다.

**실제 브라우저 렌더링·모바일 터치·픽셀 배치 검증은 접근 제한으로 미완료입니다.** DOM 검사로 화면 겹침·실제 폰트 렌더링·터치 스크롤까지 검증했다고 주장하지 않습니다. 실제 API·송금·이메일·게시 역시 실행하지 않습니다.

## 시연 범위 밖인 기존 기능

일부 기존 배너 관리·이벤트 칩 관리·엑셀 업로드/다운로드 등은 화면 위치를 유지하며 실제 작업을 실행하지 않습니다. 무응답 버튼으로 두지 않고 클릭 시 시연 범위를 안내합니다. 이를 신규 DEX 기능 구현 완료로 표시하지 않습니다.

사업팀·거래소 협의 내용은 기존 보류 목록을 유지했습니다. 이번 재점검에서 새 사업 정책을 임의로 결정하지 않았습니다.
