## 질문하신 용어 설명

### D-4는 어디의 표기인가

**거래소 상세 → 리뷰**에서 작성자에게 붙는 **✓ Verified** 배지입니다. “이 작성자가 이 거래소 계정을 테더맥스에 연동했다”는 표시입니다. 기존 결정도 이미 **연동 완료면 표시, 소유권 인증과 무관, CEX·DEX 공통**이었습니다. 과거 검토 의견을 다시 미결정으로 올린 부분을 정리했습니다.

근거: _제출본_V2/6_기존PRD_분석/확정_결정_기록_20261021.md의 D-4 확정 항목(1295행 기준).

### linkable은 무엇인가

거래소별 **연동 가능 여부**입니다. 예를 들어 소개는 노출하되 신규 계정 연동을 잠시 막으면 exposure=Y, linkable=N으로 구분할 수 있습니다. 지갑별 상태나 KYC 여부가 아닙니다.

기존 관리자 폼의 ‘가입 가능여부’가 이 값과 같은 저장 필드인지 확인하자는 개발 메모였습니다. 새 정책 결정을 요청할 내용은 아니며 구현팀이 기존 필드 매핑을 확인하면 됩니다. 통합 한도의 숫자·계산 방식도 실제 공통 설정에 연결합니다.

### 최종 결과가 성공·실패라면 무엇을 더 확인하나

최종 결과는 두 가지가 맞습니다. 전송 후 응답이 늦으면 실제로 성공했는데 아직 확인하지 못한 상태가 있을 수 있습니다. 그때 실패로 단정해 다시 보내지 않고 기존 요청의 결과를 확인하는 것은 백엔드 구현 책임입니다. 별도 상품 정책·최종 상태·이메일 추가 요구로 올리지 않습니다.

### 축약 주소 충돌과 전체 주소 보기

서로 다른 주소의 뒤 4자리가 같아 **화면에서 같은 글자로 보일 수 있다**는 뜻이었습니다. 실제 주소가 같거나 데이터가 충돌한다는 뜻은 아닙니다. 뒤 4자리 마스킹과 전체 주소 펼쳐보기로 구분합니다. 공개 출금 피드는 마스킹을 유지하고 본인 계정·출금 확인 화면에서 전체 주소를 확인합니다.

### 데이터 지연과 기존 잔액

신규 적립 데이터가 늦는 것만으로 이미 확정된 잔액이 줄어들거나 없어지지 않습니다. 기존 잔액은 유지하고 출금 가능 조건을 만족하면 출금합니다. Aster 귀속 만료 기간의 신규 적립·소급 문제는 데이터 지연과 별개로 파트너 협의 대기입니다.

### 초대 리워드 0과 설정값 0

발생액과 마진 설정값은 서로 다른 값입니다. 하위 회원 출금이 없으면 발생액이 0이고, 마진율이 0이면 하위 회원이 출금해도 지급 재원이 없어 발생액이 0일 수 있습니다. 미설정은 별도 상태로 표시하지 않고 0 처리합니다. 거래소별 실제 계약값은 합의 후 반영합니다.

## 계속 유지하는 기존 확정 사항

- 마일스톤은 현재 없는 기능으로 제외.
- DEX 외부 출금 딥링크 제거, 테더맥스 출금 버튼 사용.
- 계정별 페이백·이벤트 리워드 매칭 및 최소 10 USDT 출금 기준 유지.
- DEX도 일반 이벤트·쿠폰·초대 리워드 지원. UID 연동 3 USDT·챌린지·부스트·소유권 인증·마이포트폴리오는 기존 제외 기준 유지.
- 일반 회원 초대 리워드 출금과 관리자 Affiliate 고정 지급 계정의 범위 구분 유지.
- 포인트 관리 목록·설정·강조 거래소 선택에 DEX 포함.
