# 00.통합자료실

TetherMax DEX 캐시백 연동 프로젝트의 참조 자료 색인과 신규 자료 보관소입니다. NotebookLM과 연동하지 않습니다(`CLAUDE.md` 참조).

## 운용 원칙

- **기존 자료는 옮기지 않습니다.** 프로젝트 루트에 이미 있는 자료는 아래 색인에 위치만 적습니다. 정책 문서·점검 스크립트·산출물이 현재 경로를 인용하므로, 옮기면 근거 링크가 끊깁니다.
- **새로 받는 자료**는 아래 하위 폴더에 저장하고 이 색인에 한 줄을 추가합니다.
- 파일명: 날짜가 있는 자료 `YYYYMMDD_자료명.확장자`, 일반 자료 `자료명.확장자`.
- 민감 정보(API 키·비밀번호·회원 식별자·지갑 주소 원본 데이터)는 저장하지 않습니다.
- 자료 사이에 충돌이 있으면 **`00_DEX_최종정책.md`가 우선**합니다(정책 부록 H에 원본 간 충돌 판정).

| 폴더 | 용도 |
|---|---|
| `고객자료/` | 사업 측 요구사항, Confluence PRD, 파트너(거래소) 제공 문서 |
| `정책자료/` | 확정 정책, 결정 기록, 기존 테더맥스 규칙 |
| `인프라자료/` | 기존 시스템 구조(메뉴·라우트·API), 기술 명세 |
| `회의록/` | 파트너·내부 미팅, 대화 기록 |
| `참고자료/` | 분석·검토 자료, 캡처, 프로토타입, 경쟁·벤치마킹 |
