## 1. 개요

### 1.1 목표

테더맥스에 **새로 등록된 UID**의 초기 거래를 늘리기 위한 기간 한정 빙고 이벤트다.

- 참여 기간 동안 UID의 **거래 페이백**만큼 게이지가 쌓이고, 사용자는 3×3 빙고판의 칸을 **직접 골라 체크**한다.
- **가로·세로 줄을 완성할 때마다**, 그리고 **9칸을 모두 체크하면** 리워드를 준다. 인원 제한 없이 조건을 채운 모두에게 준다.
- 랭킹을 켠 빙고판은 빙고판 완성자 중 페이백 상위자에게 **랭킹 리워드**를 추가로 준다.
- 재사용 가능한 모듈로 만들어 **여러 빙고판(거래소별)을 동시에** 운영한다.

### 1.2 핵심 기능

| # | 기능 | 한 줄 설명 |
|---|------|-----------|
| 1 | 빙고판 생성·운영 | 백오피스에서 빙고판(거래소 1개)별로 기간, 칸 조건, 리워드 금액, 랭킹 ON/OFF, 콘텐츠를 설정 |
| 2 | 참여 자격 판정 | TUID가 아닌 **UID 기준**. 참여 시작일 30일 전부터 등록된 UID |
| 3 | 페이백 게이지 | 거래 페이백이 하루 한 번 자동 적립. 비회원 UID도 기록해 두었다가 참여 시 소급 |
| 4 | 칸 체크 | 금액 칸(게이지 사용)과 연속 페이백 칸(N일 연속 시 열림) 2종 |
| 5 | 빙고·완성 리워드 | 줄(가로 3·세로 3)마다 빙고 리워드, 9칸 완성 시 완성 리워드 |
| 6 | 랭킹 리워드 (ON/OFF) | 완성자 대상 총 페이백 순위, 별도 리워드풀, 리더보드 |
| 7 | 어뷰징 제외 | 집계 기간에 관리자가 지급 대상에서 제외 |
| 8 | 리워드 자동 적립 | 지급 기간 시작 직후 참여 UID로 이벤트 리워드 적립 |
| 9 | 혜택 노출·상세 | 혜택 목록 카드와 상세 페이지 |
| 10 | 다국어·SEO | 제목·부제목 KO/EN, SEO 6개 언어 |
| 11 | 알림 | 앱 푸시(마케팅 동의자), 결과 이메일, 운영 Slack |
| 12 | 운영 모니터링 | 빙고판별 달성 수와 예상 지급액 실시간 확인 |

### 1.3 대상 사용자

| 구분 | 열람 | 참여 | 비고 |
|------|------|------|------|
| 자격 UID 보유 회원 | O | O | TUID 가입 시점과 무관 |
| 자격 UID 미보유 회원 | O | X | 새 UID를 연동하면 참여 가능 |
| 비회원 | O | X | 열람만. 자격 UID의 게이지는 기록되어 나중에 소급 |
| 운영자 | - | - | 백오피스에서 생성·운영 |

### 1.4 설계 전제 (테더맥스 계정 구조)

| 플랫폼 특성 | 이벤트 설계 |
|-------------|-------------|
| TUID는 이메일만으로 무제한 생성 가능 | 자격·참여·리워드는 **UID 기준**으로 판정 |
| UID는 비회원 상태로도 존재 | 비회원 UID도 게이지를 기록하고 참여 시 소급 |
| UID는 다른 TUID로 이전 가능 | 참여는 새 TUID로 넘어가지 않음. 같은 빙고판 재참여 불가 |
| 사용자는 UID를 직접 연동 해제할 수 없음 | 참여 UID가 끊기는 원인은 소유권 이전·이슈 UID 지정뿐 |
| TUID 탈퇴 시 UID는 비회원 전환 | 탈퇴자에게는 리워드 미지급 |

## 2. 핵심 규칙 요약

| 영역 | 규칙 |
|------|------|
| 참여 자격 | 참여 시작일 30일 전부터 테더맥스 DB에 처음 등록된 해당 거래소 UID. 참여 기간 중 새로 등록한 UID도 가능. 같은 빙고판에 참여 기록이 있는 UID와 이슈 UID는 불가 |
| 참여 UID | 빙고판마다 TUID당 1개, 등록 후 변경 불가. 소유권 이전·이슈 UID 지정으로 잃으면 참여 기간에는 처음부터 다시(새 UID 선택 가능), 집계 이후~지급 전에는 리워드 없음, 지급 후에는 회수 없음 |
| 게이지 | 거래로 인한 페이백만 반영. 하루 1회 빙고 Batch로 갱신. 참여 기간(마지막 날 포함) 중 실행된 배치까지만 반영. 채워진 게이지는 회수하지 않음 |
| 칸 | 금액 칸: 목표 금액만큼 게이지를 써서 체크. 연속 페이백 칸: N일 연속 페이백이면 열리고 게이지를 쓰지 않음. 칸은 사용자가 고르며 취소·이동 불가. 칸 하나에는 리워드 없음 |
| 리워드 | 빙고 리워드(줄 6개) + 완성 리워드(1개) = 1인 최대 7개, USDT. 대각선 없음. 인원 제한 없음. 지급 기간 시작 시 한 번 지급 |
| 용어 | 달성 = 줄·빙고판 완성(받을 예정). 지급(적립) = 지급 기간 시작 시 참여 UID로 실제 지급 |
| 랭킹 (ON만) | 빙고판 완성자 대상, 참여 기간 총 페이백 순. 동점은 먼저 완성한 사람이 위. 집계 이후 제외·탈퇴 등으로 빈 자리는 비워 두고 당기지 않음 |
| 어뷰징 제외 | 집계 기간에 빙고판 단위로 제외, 해당 사용자 리워드 전체 미지급, 취소 불가. 사용자에게 알리지 않음 |
| 등록·수정 | 등록 즉시 확정(임시저장 없음). 금액·조건(거래소, 칸, 리워드, 랭킹, 기간)은 수정 불가, 콘텐츠만 수정 가능 |
| 강제 종료 | 어느 단계든 가능, 취소 불가. 지급 전이면 리워드 미지급, 이미 지급된 리워드는 회수하지 않음 |
| 시간 | 모든 판정은 UTC. 사용자 화면은 기기 로컬 시간으로 표시, 백오피스는 UTC |

## 3. 기간 단계

랭킹 ON은 5단계, OFF는 결과 발표를 뺀 4단계다. 단계는 각 시작일 00:00 UTC에 자동으로 바뀐다.

| 단계 | 사용자 페이지 | 참여·칸 체크 | 내용 |
|------|---------------|--------------|------|
| 노출 전 | 404 | 불가 | 등록 후 사전공개 시작 전 |
| 사전공개 | 열람 | 불가 | 빙고판·리워드 구성 안내, 자격 미리 표시 |
| 참여 | 열람 | 가능 | 게이지 적립, 칸 체크, 참여 마감 카운트다운 |
| 집계 | 열람 | 불가 | 집계 중. 어뷰징 제외 처리 |
| 결과 발표 (ON만) | 열람 | 불가 | 리워드 확정, 최종 순위 발표 |
| 지급 | 열람 | 불가 | 리워드 자동 적립 |
| 종료·강제 종료 | 404 | - | 수상자 기록은 삭제하지 않음 |

## 5. 사용자 화면 요약

- **혜택 목록**: 맥스보드 카드를 1순위로 노출. 어드민이 입력한 제목·부제목 사용.
- **혜택 상세**: 상단 TetherMax·거래소 로고, 리워드 요약, 참여 마감 카운트다운, 나의 빙고판, 전체 일정, 체크 방법, 내 리워드와 랭킹, 유의사항.
- **참여**: 상세 안에서 참여 UID를 골라 등록. 비회원은 로그인 후 같은 상세로 돌아옴.
- **원칙**: 어떤 칸을 먼저 체크할지 추천하지 않는다. 줄·빙고판 완성 직후 다음 목표를 바로 보여준다. 게이지는 "하루 한 번 업데이트돼요"만 안내하고 다음 업데이트 시각은 보여주지 않는다.
- **용어**: 리워드, 빙고, 빙고판 완성, 칸 체크, 빙고 게이지 등 확정 용어를 쓰고, 영문은 페이백을 Cashback으로 쓴다. 문장 톤은 테더맥스 언어팩을 따른다.

## 7. 비기능 요건

| 항목 | 요건 |
|------|------|
| 성능 | 상세·리더보드는 동시 조회가 많으므로 캐시. 게이지·랭킹은 하루 1회 배치 |

| 다국어 | 화면 KO/EN, SEO 6개 언어, 유의사항 15개 언어 |
| 데이터 보관 | 수상자 기록 영구 보관 |
| 반응형 | PC와 모바일을 각각 최적화 |
