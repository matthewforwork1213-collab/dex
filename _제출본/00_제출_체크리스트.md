## 1. 거래소 API 요청 문서

**영문이 발송본, 국문이 내부 검토용**이며 1:1로 대응합니다.

| 거래소 | 상태 |
|---|---|
| ApeX | 어필리에이트 API 스펙 수령. 미해결 7건 |
| Aster | **회신 대기 중.** P0 대부분 요청 단계 |
| Lighter | v2 회신 반영 완료 |
| EdgeX | **회신서 성격** — D1~D9 답변 포함 |

**발송 시 주의 2가지**
- 파트너 요율은 상업 협의 중이라 **빈칸 유지**입니다. 채워서 보내지 마십시오.
- `00_발송_내부가이드.md`는 **대외 발송 금지**입니다. 국문 폴더에만 있습니다.

## 3. 연동·출금 전체 플로우

국문·영문을 **각각 독립 파일로 분리**했습니다. 내용은 동일합니다.

핵심 메시지 하나: **DEX는 테더맥스가 출금해주지 않습니다.** DEX가 사용자 계정으로 직접 지급하고, 테더맥스는 조회·표시와 "해당 DEX로 이동"만 담당합니다.

## 4. 백오피스 관리 vs 하드코딩

대상 페이지는 **Cashback Hub**와 **DEX 나열 페이지**이며 카테고리별로 구분돼 있습니다.

## 5. 부가 서비스 DEX 연동 가능 여부

O / X / 검토필요 3단계 판정표입니다. 대상: 혜택·쿠폰, 페이백 랭킹, 포인트, 제휴사, 페이백 미션, VIP, 앱푸시, 이메일 알림 등 생태계 부가 서비스 전체.

**FCM.xlsx / EMAIL.xlsx는 국·영문이 한 파일에 들어 있어 분리할 수 없습니다.** 같은 파일을 양쪽 폴더에 두었습니다.

- FCM `FCM(en)` 시트 **100~108행** — DEX 전용 9건
- EMAIL `email(en)` 시트 **26~29행** — DEX 전용 4건
- 전부 `Purpose = DEX-related`. **마케팅성 제외, 필수 알림만.** DEX는 소유권 확인 기능을 지원하지 않는다는 전제입니다.

## 보고 시 먼저 꺼낼 3가지

**1. 출시를 막고 있는 파트너 회신 4건**

| 파트너 | 항목 |
|---|---|
| Aster | 공식 회신 자체 (P0 대부분 미회신) |
| ApeX | 원장 레코드에 캐시백 금액·지갑·토큰·지급시각 포함 여부 |
| ApeX | 인증 방식과 base URL |
| EdgeX | 실제 API 스펙 문서 (설계는 합의, 스펙 미수령) |

**2. 우리 쪽에서 막고 있는 것**

EdgeX 메인 계정 등록이 **미이행**입니다. 등록 전까지는 커미션이 들어올 계좌가 없습니다.

**3. 기한이 걸린 리스크**

Aster의 365일 레퍼럴 바인딩 갱신 방식(R13)이 확정되지 않으면 **1년 뒤 Aster 사용자 전원의 캐시백이 중단**됩니다.
