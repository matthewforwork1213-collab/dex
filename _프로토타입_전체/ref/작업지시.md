## Figma 사용
- fileKey `hsa3bSV9QmFTe2jsf6tzTm`, 세션 id `660d3975-179e-4fff-85af-c8c8424ba17b`(모든 Figma 호출에 `sessionId`로 넘긴다). Figma는 **읽기만** 한다.
- `get_design_context` 전에 MCP 리소스 `skill://figma/figma-design-to-code/SKILL.md`(서버 `claude.ai Figma`)를 읽고, 호출 때 `skillNames:"resource:figma-design-to-code"`.
- 큰 프레임은 응답이 sparse로 온다 → `get_metadata`로 자식 노드를 보고 자식 단위로 다시 호출한다. 배경 템플릿(예: `Background / D1 …`)은 다른 담당 화면이므로 다시 구현하지 말고 `C.overlay('<화면id:상태>', …)`로 겹친다.
- 응답 코드(React+Tailwind)는 참고용이다. 우리 클래스(`.btn .tf .modal .card .chip .badge .alert .tbl` 등)와 토큰 변수로 옮긴다. 새 공통 스타일이 꼭 필요하면 **자기 모듈 안에** `<style>` 없이 인라인 style 또는 그룹 접두사 클래스로 처리하고, 코어 변경이 필요하면 최종 보고에 적는다(코어 파일은 수정하지 않는다).
- 에셋(이미지·SVG)은 응답의 임시 URL에서 `curl -sL`로 `assets/<그룹접두사>-<이름>.<확장자>`에 받고 `A('파일명')`으로 쓴다. 임시 URL을 코드에 남기지 않는다. 이미 있는 공통 에셋(`logo.svg`, `ic-*.svg`, `dex-lighter|apex|edgex|aster.png`)은 다시 받지 않는다.
- 숨김(hidden) 프레임과 `정책 변경 메모`·`개발 인계 메모`·`SCREEN-LABEL` 같은 주석 프레임은 화면으로 만들지 않는다(메모 내용은 참고).
- Dark 변형은 만들지 않는다(라이트만). PC·모바일 둘 다 있으면 `figma:{pc:'…',mo:'…'}`, 한쪽만 있으면 그쪽만 적는다.

## 정책 고정 사항 (Figma보다 우선)
- DEX·CEX 캐시백 지급은 **10분 주기 자동 지급**. 회원이 누르는 출금 버튼·출금 팝업·보안 인증 화면은 없다. 출금 자리는 **비활성 `Auto Claim`** 버튼.
- 연동 시도 한도 없음(G-063) → `Verification limit reached`(L12, 모바일 `Verification limit`) 화면은 만들지 않는다.
- 게스트는 조회만 한다(출금 없음). 「귀속 기간/만료」 표현 금지(Aster referral expiring/expired 프레임은 숨김 처리된 폐기안).
- 제휴사(파트너) 출금도 DEX 지갑 가능(G-056). 파트너 허브 최소 출금 10 USDT, 회원 초대 리워드 최소 50 USDT(G-203·G-410).
- 용어: 캐시백/cashback, 게스트/guest, 연동/Link·연동 해제/Unlink. `페이백`·`payback`(경로 `/payback` 제외)·`rebate`·`non-member`·`disconnect` 금지.
- 문구는 지어내지 않는다. Figma 문구 → 없으면 V2.2 문구 → 없으면 `C.tbd('무엇','G-nnn 또는 원문 없음')`. 한국어 원문이 없으면 `T(en)`만 써서 영문이 나오게 둔다(번역하지 않는다).

## 검증
1. `node build.cjs && node tools/check.cjs <내 화면 id 접두사>` 오류 0. (다른 담당이 동시에 빌드해도 괜찮다. 남의 모듈 오류는 무시하고 내 접두사만 본다)
2. Figma 프레임이 있는 상태는 `python -I tools/shot.py <id:상태> pc|mo <scratch png>`로 찍어 Figma `get_screenshot`과 눈으로 대조하고 다르면 고친다(모든 상태가 아니라 대표 레이아웃마다).
3. V2.2 상태 목록(`ref/v22_states.txt`)의 내 담당 상태가 **빠짐없이** 상태로 있는지 확인한다(이름은 바꿔도 되지만 note에 V2.2 키를 남긴다).
